# Agent 人格与创作专家需求记录

> 当前仅记录需求，不代表已经实现。后续实现前需要先和用户逐项确认。

## 当前结论

- 暂停人格、创作专家相关改造。
- 先恢复原有咏唱助手设置行为。
- 不要凭空设计人格卡片、专家卡片、默认人格、默认专家或提示词拼装规则。
- 不要把“人格”直接等同于 `systemPrompt` 编辑框。
- 不要修改核心 Agent 规则，除非用户明确指定具体规则和编辑权限。

## 待确认问题

1. “人格”具体控制哪些内容：语气、称呼、回复长度、主动程度，还是其它行为？
2. “创作专家”具体控制哪些内容：领域知识、工作流选择、提示词方法、工具调用，还是输出格式？
3. 人格和创作专家的关系是什么：独立叠加、互斥选择，还是专家包含人格？
4. 是否允许用户创建多个自定义人格和专家？是否允许删除内置项？
5. 哪些系统规则必须始终不可编辑？是否需要在界面中展示但禁止修改？
6. 设置保存后是否立即影响当前会话，还是只对新会话生效？
7. 已有历史会话是否保留生成时的人格/专家快照？
8. 移动端和桌面端是否使用同一套编辑入口和字段？
9. 是否需要导入、导出人格/专家配置？格式和范围是什么？
10. 是否需要为不同工作流、项目或生成类型单独指定专家？

## 实现前检查清单

- 确认真实入口和实际使用的 Agent hook。
- 确认持久化字段和迁移策略。
- 确认提示词最终拼装顺序。
- 确认当前会话与新会话的生效边界。
- 先提供 UI 草图或字段表，得到确认后再编码。
